# Automated Image Captioning

This project provides an automated image captioning using a deep learning model. The application is built with TensorFlow for model handling and Streamlit for the web interface.

You can upload an image and get a caption generated by the model.

## Deployed Application

Check out the deployed application: [Automated Image Captioning](https://automated-image-captioning.streamlit.app/)

Check out Kaggle Notebook Here: [Automated Image Captioning using DL](https://www.kaggle.com/code/gauravkuchaurasiya/automated-image-captioning-using-dl)

---

## Technical Details  

- **Model Architecture:**  
  - **VGG16** for feature extraction from images.  
  - **Bahdanau Attention** to focus on important image regions when generating captions.  
  - **RNN (LSTM)** to process sequences and generate coherent captions.  

- **Dataset:**  
  - **Flickr8k Dataset** with 8,000 images, each annotated with multiple captions, providing a diverse range of image descriptions.  

- **Technologies Used:**  
  - **Python** | **TensorFlow** | **Keras** 
---

## Usage

1. Upload an image using the "Choose an image..." button.
2. The application will display the uploaded image.
3. A caption will be generated and displayed below the image.
